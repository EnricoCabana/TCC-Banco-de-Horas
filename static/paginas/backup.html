Backup

Cópia de segurança do banco de dados

Gerar backup agora

Gera uma cópia completa do banco de dados (funcionários, registros de ponto, avisos, setores — tudo) em um arquivo .sql. Você pode baixar o arquivo na hora e/ou enviá-lo por e-mail, para manter uma cópia guardada fora do servidor.

Como funciona
  • Baixar backup gera um .zip com dois arquivos: o dump do banco (.sql) e a assinatura de integridade (integridade.sha256), e faz o download no seu navegador.
  • Verificação de integridade: ao restaurar um .zip, o sistema recalcula o hash SHA-256 do dump e compara com a assinatura. Se o arquivo tiver sido alterado ou corrompido, a restauração é recusada e o banco não é tocado.
  • Restaurar backup sobe o .zip (ou um .sql solto, de backups antigos) e recarrega o banco com os dados dele. Atenção: substitui os dados atuais — use com cuidado.
  • Restaurar: o passo a passo para recuperar o banco a partir de um arquivo de backup está em docs/backup_restauracao.md.
